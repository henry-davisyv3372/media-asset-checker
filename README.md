## What Asset Checker Does

Asset Checker gives creative, marketing, and production teams a way to verify media before placing or delivering it. For both images and videos, it checks criteria including resolution, aspect ratio, file size, format, codec, duration, frame rate, and whether an audio track is present.

The application is delivered as a standalone HTML page that runs in a web browser. Media stays on the local machine during analysis, while the browser-based workflow can also produce consistent filenames and package organized files into ZIP archives.

---

## Capabilities

- Evaluate image and video files against placement specifications.
- Check dimensions, aspect ratios, file sizes, and container formats.
- Examine PNG transparency information and JPEG color models.
- Read video codec, frame rate, duration, and audio-track details.
- Sort compatible placements by how closely their aspect ratio and scale match.
- Create standardized names for checked assets.
- Assemble ZIP archives without leaving the browser.
- Operate from a standalone HTML file with no server or external dependencies.
- Analyze chosen files locally instead of uploading them.

## How to Use

1. Open the Asset Checker HTML page in a web browser.
2. Choose the image or video files that need review.
3. Compare each file's reported characteristics with the listed placement requirements.
4. Use the aspect-ratio and scale-proximity rankings to assess compatibility.
5. Check image-specific information, including alpha channels and color models.
6. Review video codec, frame rate, duration, and audio-track information.
7. Create standardized filenames for the reviewed files if required.
8. Export the prepared assets as a ZIP archive when appropriate.

The complete file-checking process runs inside the browser.

## Frequently Asked Questions

### Who should use Asset Checker?

Asset Checker is intended for anyone preparing, checking, or delivering image and video files for platform placements.

### Are selected files sent to a server?

No. Files are analyzed locally within the browser and are not uploaded to a server.

### Which image characteristics can be validated?

Image checks cover resolution, aspect ratio, file size, container format, PNG alpha-channel information, and JPEG color models.

### What information is available for videos?

The video inspection includes container format, codec, frame rate, duration, and audio-track details.

### Does Asset Checker suggest compatible placements?

Yes. The tool can rank compatible placements according to aspect-ratio and scale proximity.

### How can I get a newer version?

Open the repository's latest build link and replace your local standalone HTML file with the newer build when one is available.

### Does the application have a settings store?

The standalone workflow does not use a separate settings store. Requirements and validation output are managed through the browser interface.

### What can I try if the page fails to run?

Use a current web browser, reopen the standalone HTML file, and make sure the selected files are available and supported by that browser.
